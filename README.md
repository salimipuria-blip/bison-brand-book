# BISON Z — Brand Book

کتاب برند تعاملی **BISON Z** / Generation Z Adventures.

## مشاهده

فایل `index.html` را در مرورگر باز کنید، یا:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

سوییچ زبان: **FA / EN**

- نماد بایزون
- سامانه لوگو و حریم امن
- پالت رسمی `#E5E300` `#0D0D0D` `#2E7D32` `#E60000`
- حروف‌نگاری
- شخصیت‌های برند
- جهت عکاسی، صدا، کاربرد و قوانین
